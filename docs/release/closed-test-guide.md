# NocturneL Closed-Test Guide

Google requires at least 12 testers to remain opted in for 14 continuous days for a new personal account. Recruit 15–20 people to allow for attrition. Every tester needs an eligible Google Account and must not opt out during the window.

NocturneL is a paid app. Give each tester a paid-app promo code, the closed-test opt-in URL, and these instructions:

1. Redeem the promo code using the same Google Account used for the closed test.
2. Opt in, install from Google Play, and remain opted in for the full test.
3. Select a local music folder and perform a scan.
4. Browse albums/artists, search, favourite a track, and review history.
5. Play, pause, seek, skip, edit the queue, and test lock-screen controls.
6. Create a playlist and try export/import.
7. Use the app in airplane mode.
8. Open Settings and test PRIVACY POLICY.
9. Send feedback to mathew.stewart@gmail.com using the feedback template.

Do not commit tester email addresses, Google Accounts, device identifiers, or raw private feedback to this repository. Keep only pseudonymous summaries needed for the production-access application.
